# المرحلة 0: إصلاحات بيانات على الإنتاج (للموافقة فقط، مش متطبقة)

مفيش ملف منهم migration، ومفيش حاجة منهم بتتشغل لوحدها. كل ملف بيبدأ بـ SELECT للمعاينة، وبعده التعديل جوه BEGIN/ROLLBACK
(غيّر ROLLBACK لـ COMMIT بعد ما الأرقام تطابق المعاينة).
