اعتبارًا من 02-08-2026: المخزن الرئيسي (`5ec781b5-685b-4806-b59a-83a79ea5662c`) كل حركاته **يدوية** فقط
(وارد/صادر يسجله مسؤول المخزن).

- `public.is_manual_stock_warehouse(uuid)` تحدد المخازن اليدوية (حاليًا المخزن الرئيسي فقط).
- `dispatch_order_stock` ترجع `manual_warehouse_skipped` بدون أي حركة عندما يكون مصدر الأوردر المخزن الرئيسي.
- `handle_order_status_stock` تخرج فورًا (لا خصم عند «تم التوصيل»، ولا إرجاع عند الإلغاء) للمخزن الرئيسي.
- الخصم التلقائي يبقى كما هو لمخزن العجوزة ومخازن العملاء.

أي كود جديد يخصم من المخزن الرئيسي تلقائيًا بسبب طلب = مخالف لهذه القاعدة.
