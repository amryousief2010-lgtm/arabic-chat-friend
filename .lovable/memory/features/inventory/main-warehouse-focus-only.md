اعتبارًا من 02-08-2026: كل العمل الحالي على المخزون يخص **المخزن الرئيسي فقط**
(`5ec781b5-685b-4806-b59a-83a79ea5662c`).

ممنوع أي تعديل بيانات أو منطق أو حركات على: مخزن فرع العجوزة، هايبر كارفور،
هايبر هيلثي تيست، مخزن أدوات التغليف، مخزن خامات مصنع اللحوم — إلا بطلب صريح من المستخدم.

**السبب:** المستخدم يقوم بضبط الجرد اليدوي للمخزن الرئيسي ولا يريد أي تغيير يشوّش الأرصدة الأخرى.
